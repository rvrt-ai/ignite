# Ignite · rvrt

Plugin do Claude para quem participa dos workshops Ignite da rvrt.

## Instalar no Claude Desktop (Cowork)

1. Abra **Customize** e depois **Plugins**.
2. Clique em **Add** > **Add marketplace** e cole: `rvrt-ai/ignite`
3. Encontre o plugin **Ignite** e clique em **Install**.

## Começar

Crie uma pasta `Meu projeto Ignite`, crie um projeto no Cowork a partir dela, abra uma tarefa nova e digite `/ignite:onboarding`.

Guia completo: [ignite/README.md](ignite/README.md).
